## Comandi principali Git:

```bash
┌─────────────────────────────────────────────────────────────┐
│ 1. cd /percorso/directory                                   │
│    ↓                                                        │
│ 2. git init                                                 │
│    ↓                                                        │
│ 3. git add .                                                │
│    ↓                                                        │
│ 4. git commit -m "Initial commit: ..."                      │
│    ↓                                                        │
│ 5. git remote add origin https://github.com/EnricoET/NoteLezioni.git             
│    ↓                                                        │
│ 6. git branch -M main                                       │
│    ↓                                                        │
│ 7. git push -u origin main                                  │
│    ↓                                                        │
│   CARICATO SU GITHUB!								          |
└─────────────────────────────────────────────────────────────┘
```
```bash
┌─────────────────────────────────────────────────────────────┐
│ MODIFICHE FUTURE:                                           │
│                                                             │
│ 1. git add .                                                │
│    ↓                                                        │
│ 2. git commit -m "Descrizione modifica"                     │
│    ↓                                                        │
│ 3. git push origin main  (o solo: git push)                 │
│    ↓                                                        │
│  AGGIORNATO SU GITHUB!									  │
└─────────────────────────────────────────────────────────────┘
```
```bash
┌─────────────────────────────────────────────────────────────┐
│ COPIARE IN LOCALE:                                           │
| git clone https://github.com/EnricoET/NoteLezioni.git       | 
└─────────────────────────────────────────────────────────────┘
```
